Contributing

Help shape the standard

ERC-8473 is a draft, so now is when feedback changes it most. Reviews of the specification, second implementations, and bug reports on the reference are all welcome.

Discuss the standardOn the Ethereum Magicians thread, the ERC's discussions-to. Questions, objections and proposed changes to the specification go here. Report a bugAs a GitHub issue, for anything wrong in the reference contracts, the tests, or this site. Send a changePull requests are welcome for code and docs. Run the checks below first.

How a change moves

  • The draft and the code change together. A change to an interface, to the reference token's _update, _move or _permits, or to a selector updates the draft in the same change. npm run check:erc fails when the draft's code blocks drift from contracts/.
  • The guide changes with them. A change to anything this site's hand-written pages explain updates those pages in the same change. The specification page and this page's README sections are generated, so they follow on their own.
  • Every check passes. Lint, format, both test profiles, Slither, the draft check and the site build. The commands are below.
  • The ERC pull request follows. Changes land here first. Until ethereum/ERCs#2128 merges, the maintainer copies changes to the draft and its assets there.
npm run lint:sol && npm run fmt:check && npm test && npm run test:isolated && slither . && npm run check:erc
scripts/fetch-tool.sh pandoc && npm run site

npm run site builds this site into _site/ and fails on a broken internal link. Preview it with python3 -m http.server -d _site.
